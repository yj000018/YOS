## Architecture & Stack
Modern full-stack web applications built primarily with React 19, Next.js, TypeScript, Tailwind CSS, and shadcn/ui components. Backend systems use Node.js/Express with tRPC for type-safe APIs, PostgreSQL and SQLite databases with Drizzle ORM. AI integration via OpenAI API for spiritual guidance, content generation, and ghostwriting features. Authentication systems with role-based access control (RBAC). Multilingual support infrastructure (FR/IT/EN). Payment integration with subscription models. Deployment on [Manus.space](http://Manus.space) platform with permanent public URLs. Notion serves as primary memory persistence layer with automated recall systems. Audio production using OpenAI TTS with mixing capabilities. Visual design using canvas animations, SVG graphics, CSS animations, and glassmorphism effects.
