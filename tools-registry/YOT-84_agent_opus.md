## Business Value
Agent Opus permet de créer des vidéos narratives complètes à partir de simples prompts, scripts ou assets de référence. Il offre une solution de bout en bout pour la production vidéo automatisée dans l'écosystème Y-OS.

## Capabilities
- Génération de vidéos narratives complètes
- Création à partir de prompts textuels
- Création à partir de scripts structurés
- Intégration d'assets de référence uploadés

## Dependencies
- Compte Agent Opus actif
- Authentification OAuth via MCP

## Known Limits & Bugs
- La durée maximale des vidéos peut être limitée selon le plan d'abonnement.
- Le temps de rendu peut être long pour les vidéos complexes.

## Workarounds & Lessons
- Découper les scripts longs en scènes plus courtes pour un meilleur contrôle de la génération.
- Fournir des assets de référence de haute qualité pour améliorer la cohérence visuelle.
