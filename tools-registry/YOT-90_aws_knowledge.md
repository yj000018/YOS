## Business Value
Provides immediate, contextual access to the vast repository of AWS documentation, best practices, and Standard Operating Procedures (SOPs). This accelerates cloud architecture design, troubleshooting, and infrastructure-as-code development within the Y-OS ecosystem.
## Capabilities
- Search and retrieve AWS official documentation.
- Access architectural best practices and Well-Architected Framework guidelines.
- Fetch Standard Operating Procedures (SOPs) for various AWS services.
- Query specific service limits, API references, and configuration examples.
## Dependencies
- Active internet connection to query AWS documentation endpoints.
- No specific AWS credentials required for public documentation access.
## Known Limits & Bugs
- May not have real-time updates for services released within the last 24 hours.
- Search results might be broad; requires specific queries for niche service features.
## Workarounds & Lessons
- Use exact service names and feature keywords to narrow down search results.
- Cross-reference retrieved SOPs with the current date to ensure they apply to the latest AWS service versions.
