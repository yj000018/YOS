# Roadmap — Session XII
## Naissance de la Cathédrale Invisible

**Date :** 27 juillet 2026  
**Statut :** feuille de route fondatrice, non canonisée.

Ce document organise l'ordre de travail envisagé après la Session XII. Il ne fixe pas un calendrier rigide. Il protège la séquence de maturation afin d'éviter que la vitesse d'exécution ne détruise la profondeur de l'œuvre.

---

## Phase 0 — Sauvegarde immédiate

Objectif :

Préserver tout ce qui peut encore l'être avant toute réécriture.

Actions :

- conserver le backup général de session ;
- préserver le dialogue encore accessible ;
- extraire les formulations remarquables ;
- isoler les épiphanies ;
- isoler les métaphores ;
- consigner les décisions ;
- cartographier les futurs documents ;
- enregistrer les questions ouvertes ;
- formaliser les principes éditoriaux ;
- écrire une réflexion de clôture.

Critère de sortie :

Aucune idée majeure encore accessible ne dépend uniquement de la conversation active.

---

## Phase 1 — Archive intégrale de la session

Objectif :

Créer une archive quasi verbatim de la conversation fondatrice lorsque son contenu complet sera disponible.

Actions :

- recevoir la conversation complète ;
- préserver l'ordre exact des échanges ;
- distinguer clairement utilisateur et assistant ;
- conserver les formulations originales, y compris les hésitations ;
- ajouter seulement les métadonnées nécessaires ;
- ne pas corriger le style de la source ;
- ne pas fusionner l'archive brute avec les synthèses actuelles.

Livrable possible :

```text
CANON/archives/sessions/2026/2026-07-27-session-xii/01-dialogue-raw-complete.md
```

Critère de sortie :

La conversation peut disparaître de l'interface sans que sa substance historique soit perdue.

## Phase 3 — Clarifier les états de maturité

Objectif :

Rendre visible la différence entre source, extraction, brouillon et Canon.

États de travail envisagés :

1. `raw` ;
2. `preserved` ;
3. `extracted` ;
4. `crystallizing` ;
5. `candidate` ;
6. `canonical` ;
7. `translated` ;
8. `deprecated-but-preserved`.

Actions :

- préciser les critères de passage ;
- indiquer le statut dans chaque document ;
- préserver l'historique des changements d'état.

Critère de sortie :

Aucun lecteur ne confond une intuition de session avec un texte canonique définitif.

## Phase 4 — Formaliser les principes éditoriaux

Objectif :

Établir la méthode de transformation d'une source en texte canonique.

Principes à formaliser :

- la source est sacrée ;
- aucune inspiration ne sera perdue ;
- préserver avant de polir ;
- clarifier sans appauvrir ;
- rendre plus intemporel sans effacer l'origine ;
- garder les variantes significatives ;
- documenter les choix de réécriture ;
- distinguer correction, cristallisation et canonisation.

Livrables possibles :

```text
CANON/EDITORIAL-PRINCIPLES.md
CANON/CANONIZATION-PROTOCOL.md
CANON/PRINCIPLE-OF-SOURCE.md
```

Critère de sortie :

Le passage de la conversation au Canon devient reproductible et auditable.

## Règles transversales

À toutes les phases :

1. ne jamais supprimer une source pour simplifier une version finale ;
2. ne jamais annoncer un commit sans SHA confirmé ;
3. préserver les variantes significatives ;
4. distinguer ce qui est décidé de ce qui est pressenti ;
5. éviter la production massive de textes superficiels ;
6. préférer une formulation mûre à dix formulations rapides ;
7. maintenir la traçabilité entre source et Canon ;
8. laisser l'œuvre dépasser ses premiers bâtisseurs.

1. terminer les archives `08`, `09` et `10` ;
2. vérifier que les fichiers `00` à `10` existent réellement dans Git ;
3. créer un index local de Session XII ;
4. récupérer la conversation complète ;

6. comparer l'archive complète avec les synthèses ;
7. compléter les éléments manquants ;
8. seulement ensuite commencer la cristallisation canonique.

Cette roadmap ne mesure pas la réussite par le nombre de documents produits.
