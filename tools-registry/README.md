## Convention de nommage

```
YOT-{id}_{slug}.md
```

- `YOT` = Y-OS Tool
- `{id}` = numéro séquentiel (prochain : **YOT-74**)
- `{slug}` = nom court en minuscules, underscores

## Frontmatter obligatoire

```yaml
---
tool_id: YOT-XX
tool_name: Nom de l'outil
tool_type: MCP Connector | REST API | CLI Tool | ...
category: Memory / Knowledge | Design / Visual | Automation | ...
status: Production | Experimental | A tester | Deprecated
pricing: Free | Freemium | Payant | Pay-as-you-go | Inclus Y-OS
source_type: Officiel | Communauté | Custom Y-OS
source_url: https://...
auth_credentials: OAuth MCP | API Key Env Var | 1Password Item | No Auth
last_updated: YYYY-MM-DD
---
```

## Workflow de mise à jour

1. Nouvel outil découvert → créer `YOT-{n+1}_{slug}.md`
2. Nouvelle capacité API/MCP → mettre à jour la fiche existante
3. Outil décommissionné → changer `status: Deprecated` + noter la raison
4. Commit message : `tools: update YOT-XX {nom} — {raison}`
